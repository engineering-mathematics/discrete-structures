# Changelog

## 0.1.0 (unreleased)

### Added
- `MathSet` with the standard set algebra, power set and Cartesian product.
- Counting: `factorial`, `permutation_count`, `combination_count`, `multiset_count`, `catalan`, lazy `permutations` and `combinations`.
- Logic: gates, `truth_table`, `is_tautology`, `is_satisfiable`, `are_equivalent`.
- `DirectedGraph`: structure queries, `topological_order`, `reachable`, `shortest_path`, `tree_text`.
